# Contributing to Movie Night

Welcome! We're excited that you're interested in contributing to our club's movie night picker. Whether you're fixing a bug, adding a feature, or improving documentation, your help is appreciated.

## Development Setup

1. Fork this repository and clone your fork locally.
2. Create a new branch for your changes: `git checkout -b my-feature`.
3. Install dependencies: `pip install -r requirements.txt`.
4. Make your changes and test them locally.
5. Commit your changes and push to your fork.
6. Open a pull request against the `main` branch for review.

## Getting Help

- If you have questions, please open an issue and describe what you need help with.
- For bugs, include steps to reproduce the problem and your environment details.
- Be kind and respectful in all interactions. We're all here to learn and have fun!
